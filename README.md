# Cyber Threat Analytics Platform

## About
A Power BI-based project to analyze cyber threats, emergency incidents, environmental risks, and response performance using interactive dashboards.

## Key Features
- Threat incident monitoring
- Geographical threat hotspot analysis
- Incident trends and severity analysis
- Emergency response performance tracking
- Environmental risk analysis

## Tools Used
- Power BI
- Power Query
- Excel/CSV

Milestone 1: Data Preparation and Validation
